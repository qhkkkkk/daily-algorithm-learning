## 什么是指针

在算法描述里，“指针”常指记录当前处理位置的变量。对数组来说可以是整数下标，对链表来说也可以是节点引用。双指针就是让两个位置协同完成处理，不是只要用了两个变量就自动得到一种正确算法。

## 快慢指针

两个位置通常沿相同方向移动，但前进的时机或步长不同。

移动零中：

- i 扫描所有元素，每轮前进。
- pos 记录下一个非零元素的目标位置，遇到非零才前进。
- 二者从 0 开始，始终 pos <= i；不是必须让 i 每次走两格。

```text
输入：[0, 1, 0, 3, 12]
       ↑
     pos/i

看到 1 后，把它换到 pos：
      [1, 0, 0, 3, 12]
          ↑  ↑
         pos i（下一轮）
```

链表判环里也常用快慢指针，快指针一次走两步、慢指针一次走一步。这是另一个具体用法，不要套到移动零的步进规则上。

## 左右指针

一个位置从左开始，一个位置从右开始，根据条件向中间移动，例如反转数组时交换两端。

[盛最多水的容器](../problems/two-pointers/0011-container-with-most-water/README.md)使用 left = 0、right = n−1，面积是较矮高度乘下标差。每轮先记录面积，再移动较矮的一端；保留短边、只收缩另一端，面积不会超过已经记录的当前值。

该题不要求高度数组有序。能否移动端点，取决于是否证明排除的组合不可能改善答案，不能把“左右指针”理解为所有题都移动短边。

| 类型 | 位置如何移动 | 常见用途 |
| --- | --- | --- |
| 快慢指针 | 通常同向，移动节奏不同 | 原地整理、链表判环 |
| 左右指针 | 从两端向中间 | 反转、有序数组配对、盛最多水的容器 |
| 滑动窗口 | 左右边界维护连续区间 | 满足条件的子串或子数组 |

滑动窗口常可看作双指针的一种用途，但窗口通常另维护计数、和等状态，本仓库单独分类便于复习。

两数之和原题数组无序，不能直接照搬有序数组的左右夹逼；排序还会改变下标关系，需要额外记录原位置。因此我们把原题主解归为哈希表。

## 如何自己写出来

写代码前先用自然语言确定：

1. 两个变量分别代表什么位置？
2. 什么条件下移动哪个变量？
3. 哪些位置已经整理好、哪些尚未处理？
4. 每轮如何保持这个约定？
5. 如何保证下标合法且循环结束？

移动零的回答：扫描到非零时，把它接到前面已经整理好的非零序列末尾。已扫描部分剩下的位置都是零。先理解这句话，再写交换和 pos 加一。
