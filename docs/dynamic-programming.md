## 先给状态一个准确含义

动态规划先明确一个较小问题的答案，再利用已求出的答案计算下一个问题。不要只背“一个循环加一个 max”。

以最大子数组和为例，适合的状态是：

```text
dp[i] = 必须以 nums[i] 结尾的最大连续非空子数组和
```

“必须以 i 结尾”十分重要。如果写成“前 i+1 个数中出现过的最大和”，最好的那段可能早已结束，就不能保证直接接上 nums[i+1] 仍然连续。

例如 [5, -10, 1]，走到 -10 时，历史最大和为 5，但这段 [5] 没有以 -10 结尾；直接把下一步的 1 接到这个历史最大值上，会跳过中间的 -10，产生不连续的错误结果。

## 从分类讨论写出转移

考虑以 i 结尾的子数组：

- 如果只有一个元素，就是 nums[i]。
- 如果长度至少为二，去掉最后的 nums[i] 后，剩下的部分必须以 i−1 结尾。其中最大的和是 dp[i−1]。

所以：

```text
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

只保留最大的旧状态不会漏掉最优结果：同一个终点下，和较小的那段接上相同的后续元素后，仍比原来较大的那段更小。新起点则由每轮的 nums[i] 单独考虑。

## 为什么可以只保存上一步

转移只读取 dp[i−1]，不再读取更早的 dp。因此求“最大和这个数值”时，可以用一个变量覆盖旧值：

```python
current = max(nums[i], current + nums[i])
```

右侧使用旧 current，整句完成后，左侧保存新 current。下一轮再使用这个新值，所以 current 可以代表三个、四个乃至更多元素的连续和。

这是滚动状态：不再保存整个 dp 数组，辅助空间从 O(n) 降为 O(1)。如果任务还要求恢复具体选择或区间，则可能需要额外保存信息，应按新要求重新设计。

## 初始化与历史答案

本题要求非空，所以初始状态为：

```python
current = nums[0]
ans = nums[0]
```

从下标 1 开始转移，每次更新：

```python
current = max(nums[i], current + nums[i])
ans = max(ans, current)
```

current 保存“必须在这里结束”的结果，ans 保存“到目前为止最好”的结果。两者不能混用。

[-3, -2] 的答案是 -2，不能因为习惯把最大值初始化为 0 就返回空数组的和。初始化要服从状态含义和题目约束。
