## 双指针

适合用两个位置协同完成数组、字符串或链表的扫描。是否能使用某种指针移动规则，需要结合题目证明。

| 题目 | 标签 | 核心提示 |
| --- | --- | --- |
| [0283 移动零](../problems/two-pointers/0283-move-zeroes/README.md) | 数组、快慢指针、原地修改 | 一个位置扫描，另一个位置接收非零元素 |

## 后续分类参考

以下是归档指南，尚未收录的分类不建立空题目目录。

| 主分类目录 | 识别线索 |
| --- | --- |
| `array-string` 数组与字符串 | 基本遍历、模拟、下标处理 |
| `hash-table` 哈希表 | 存在性、计数、数值到位置的映射 |
| `two-pointers` 双指针 | 快慢扫描、左右夹逼、原地整理 |
| `sliding-window` 滑动窗口 | 维护连续区间，左右边界按条件移动 |
| `prefix-sum` 前缀和 | 重复查询区间和或计数 |
| `binary-search` 二分查找 | 有序性或可证明的单调条件 |
| `linked-list` 链表 | 节点连接与断开、反转 |
| `stack-queue` 栈与队列 | 后进先出、先进先出、单调栈 |
| `tree` 树 | 二叉树、搜索树、树的递归与遍历 |
| `heap` 堆 | 反复取最小或最大、前 k 个 |
| `graph` 图 | 连通性、拓扑、最短路、并查集 |
| `backtracking` 回溯 | 枚举选择、撤销选择、剪枝 |
| `dynamic-programming` 动态规划 | 状态、转移、重复子问题 |
| `greedy` 贪心 | 证明每步局部选择足够 |
| `bit-math` 位运算与数学 | 二进制性质、数论、数学推导 |

归档时选最能体现主要解法的分类，其余作为标签。例如移动零属于数组题，但主要训练快慢指针；两数之和虽能暴力枚举，主要归入哈希表。
