## 题意与例子

在数组中找一段**连续、至少包含一个元素**的子数组，使这一段的元素和最大，返回这个最大和。返回的是整数，不需要返回区间本身，也不需要修改输入。

```text
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
答案 = 6
对应的一段是 [4, -1, 2, 1]
```

子数组可以从任意位置开始，在任意位置结束；不能跳过中间的负数直接拼接两个正数。负数也可能留在最优子数组里，上例的 -1 就应保留。

```text
nums = [-3, -2]
答案 = -2，选 [-2]
```

不能返回 0，因为选择空数组不符合题意。

## 从朴素思路到主要解法

### 先想一个能枚举完整的做法

固定起点 left，然后让终点 right 逐步向右，每次把新元素加入区间和，并更新最大值。枚举所有起点与终点可以覆盖全部连续非空子数组，时间 O(n²)，辅助空间 O(1)。

题目最多有 100000 个元素，双重枚举开销很大。接下来思考：到达同一个终点时，是否必须保留所有起点？

### 把问题缩小为必须以当前位置结尾

定义两个变量：

| 变量 | 含义 |
| --- | --- |
| current | 必须以当前元素结尾的最大子数组和 |
| ans | 到目前为止，所有已经处理过的终点中的最大子数组和 |

遇到 nums[i] 时，以它结尾的连续子数组只有两类：

1. 只有当前元素，从 nums[i] 重新开始。
2. 不止一个元素，接在前一位置结尾的某段子数组后面。

第二类只需要选择前一位置结尾时最大的那段，因为它们接上的都是相同的 nums[i]。于是：

```python
current = max(nums[i], current + nums[i])
ans = max(ans, current)
```

第一行右侧的 current 是更新前的值，代表“以 i−1 结尾的最好结果”；赋值之后才变成“以 i 结尾的最好结果”。第二行使用新 current 更新历史答案。

### 为什么归入动态规划

如果用 dp[i] 表示“必须以 i 结尾的最大子数组和”，关系为：

```text
dp[0] = nums[0]
dp[i] = max(nums[i], dp[i-1] + nums[i])
答案 = 所有 dp[i] 中的最大值
```

每一步只依赖前一步，不需要保存整份 dp 数组。用 current 覆盖上一状态，就把辅助空间从 O(n) 降为 O(1)。这种扫描解法也称 Kadane 算法。

补充讲解：也可以从贪心角度理解。前一段的总和为负，接上它只会让当前结果更小，应从当前位置开始；总和为正则接上；为零时两种选择的和相同。这里判断的是**前一整段的和**，不是看当前元素是否为负。

## 逐步推演与正确性

### 完整推演题目示例

初始化 current = ans = -2，然后从下标 1 开始：

| 下标 | 当前数 | 单独开始 | 旧 current 加当前数 | 新 current | ans | 新 current 对应的一段 |
| ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 0 | -2 | — | — | -2 | -2 | [-2] |
| 1 | 1 | 1 | -1 | 1 | 1 | [1] |
| 2 | -3 | -3 | -2 | -2 | 1 | [1, -3] |
| 3 | 4 | 4 | 2 | 4 | 4 | [4] |
| 4 | -1 | -1 | 3 | 3 | 4 | [4, -1] |
| 5 | 2 | 2 | 5 | 5 | 5 | [4, -1, 2] |
| 6 | 1 | 1 | 6 | 6 | 6 | [4, -1, 2, 1] |
| 7 | -5 | -5 | 1 | 1 | 6 | [4, -1, 2, 1, -5] |
| 8 | 4 | 4 | 5 | 5 | 6 | [4, -1, 2, 1, -5, 4] |

表中的区间只是解释 current 的含义，实际源码不存子数组，也不会复制它们。最后 current 为 5，但历史最好结果 ans 为 6，所以返回 ans。

### 为什么只保留一个current不会漏掉其他起点

假设两段都以同一位置结尾，和分别为 3 和 0。下一步接上同一个 2：

```text
原来较大的：3 + 2 = 5
原来较小的：0 + 2 = 2
```

较小的那段接上相同数字后仍不可能反超。因此，对同一个终点，只保留最大的那段即可。下一步再额外考虑“只取新数字”，就同时覆盖了从新位置开始的情况。

### 正确性依据

1. 初始 current = nums[0]，是以第一个位置结尾的唯一非空子数组和；ans 也正确。
2. 假设旧 current 已是以 i−1 结尾的最大和。以 i 结尾的子数组，要么只有 nums[i]，要么是某段以 i−1 结尾的子数组加上 nums[i]。取两类中的最大值，便得到新的 current。
3. 更新 ans = max(ans, current)，就保留了所有已处理终点中的最大结果。
4. 每段非空子数组都有唯一的终点。处理完最后一个位置后，ans 覆盖所有可能终点，所以是全局最大和。

## 三种语言源码

保留本次完成的 current、ans 与按下标遍历的写法。这里只统一排版、添加解释性注释；C++ 显式写出头文件、std::，并转换长度类型，便于本地编译。

### Python 3

[源码](python/solution.py)。与本次代码保持相同接口；list[int] 类型注解需要 Python 3.9 或更新版本。

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        # 子数组必须非空，用首元素初始化，才能正确处理全负数。
        current = nums[0]
        ans = nums[0]

        for i in range(1, len(nums)):
            # 以当前位置结尾：重新开始，或接上前一段。
            current = max(nums[i], current + nums[i])
            ans = max(ans, current)

        return ans
```

### C++

[源码](cpp/solution.cpp)。max 来自 algorithm 头文件，vector 来自 vector 头文件。

```cpp
#include <algorithm>
#include <vector>

class Solution {
public:
    int maxSubArray(std::vector<int>& nums) {
        // 子数组必须非空，不能把全负数输入的答案初始化为 0。
        int current = nums[0];
        int ans = nums[0];
        int n = static_cast<int>(nums.size());

        for (int i = 1; i < n; ++i) {
            // current 是以当前位置结尾的最大和，不是历史最大值。
            current = std::max(nums[i], current + nums[i]);
            ans = std::max(ans, current);
        }
        return ans;
    }
};
```

### Java

[源码](java/Solution.java)。Math 属于 java.lang，直接使用 Math.max，无需额外 import。

```java
class Solution {
    public int maxSubArray(int[] nums) {
        // 子数组必须非空，用首元素初始化，才能正确处理全负数。
        int current = nums[0];
        int ans = nums[0];

        for (int i = 1; i < nums.length; i++) {
            // 以当前位置结尾：重新开始，或接上前一段。
            current = Math.max(nums[i], current + nums[i]);
            ans = Math.max(ans, current);
        }
        return ans;
    }
}
```

## 本次困惑与解答

以下问题来自本次对话；初始化等补充知识在后面单独标明。

### 从第二个第三个位置开始的情况怎么办

每一轮的第一个候选值 nums[i]，就是“从当前位置重新开始”。

本次用过的例子 nums = [-2, -3, 4, -1, 2]：

```text
初始：current = -2，对应 [-2]

遇到 -3：
max(-3, -2 + -3) = -3
选择从第二个位置重新开始，对应 [-3]

遇到 4：
max(4, -3 + 4) = 4
选择从第三个位置重新开始，对应 [4]

遇到 -1：
max(-1, 4 + -1) = 3
接着前面，对应 [4, -1]

遇到 2：
max(2, 3 + 2) = 5
接着前面，对应 [4, -1, 2]
```

不用额外再写一个起点循环。“重新开始”在每个位置都被考虑；以前较差的起点可以舍弃，是因为它们接上相同的后续元素也不会更好。

### 这不是两个两个比较吗，怎么继续累加

max 的确接收两个候选值，但每个候选值可以代表一整段的和，不等于只考虑两个数组元素。

本次例子 nums = [4, -1, 2, 1]：

| 处理进度 | 计算 | 新 current | 对应的一段 |
| --- | --- | ---: | --- |
| 初始化 | 首元素 | 4 | [4] |
| 遇到 -1 | max(-1, 4−1) | 3 | [4, -1] |
| 遇到 2 | max(2, 3+2) | 5 | [4, -1, 2] |
| 遇到 1 | max(1, 5+1) | 6 | [4, -1, 2, 1] |

第三步使用的 3，已经是前面整段 [4, -1] 的和；第四步使用的 5，又是前三个数的和。current 每轮更新，下一轮继续使用更新后的值。

这不是不断计算 nums[i−1] + nums[i]。那样只会看到相邻两个元素，确实会漏掉更长的区间。

### Python写完以后怎样换成C++和Java

算法与更新顺序都不变，只替换长度、最值函数和代码块语法：

```text
Python：for i in range(1, len(nums)):
C++：   for (int i = 1; i < n; ++i)
Java：  for (int i = 1; i < nums.length; i++)
```

C++ 的 n 来自 nums.size()；Java 数组用 length 属性。Python/C++/Java 都可用 nums[i] 读取这个整数元素。

C++ 的 std::max 与 Python 的 max 在本题都比较两个整数；Java 要写 Math.max。C++/Java 的赋值和 return 语句末尾加分号，用花括号包围循环体。

### 补充讲解：为什么初始化不能随便用0

题目要求非空。如果 ans 初始化为 0，输入 [-3, -2] 时就会保留一个不存在的“空数组和 0”，结果错误。current 与 ans 都从首元素初始化，最容易统一处理全负数和单元素输入。

数组只有一个元素时，循环不执行，直接返回 nums[0]。

### 补充讲解：为什么还要单独保存ans

current 必须以当前位置结尾，可能在后面下降。比如 [5, -10, 1]：

```text
current 依次为：5、-5、1
ans     依次为：5、5、5
```

只返回最后的 current 会得到 1，漏掉之前的 [5]。ans 的作用就是保存已经出现过的最大值。应先更新 current，再更新 ans，确保最后一个位置的结果也被考虑。

## 语言差别与常用接口

| 内容 | Python 3 | C++ | Java |
| --- | --- | --- | --- |
| 输入类型 | list[int] | `std::vector<int>&` | `int[]` |
| 整数变量 | `current = nums[0]` | `int current = nums[0];` | 同 C++ |
| 数组长度 | `len(nums)` | `nums.size()` | `nums.length` |
| 从第二个位置遍历 | `range(1, len(nums))` | `i = 1; i < n; ++i` | `i = 1; i < nums.length; i++` |
| 比较两个数 | `max(a, b)` | `std::max(a, b)` | `Math.max(a, b)` |
| 读取元素 | `nums[i]` | `nums[i]` | `nums[i]` |
| 返回整数 | `return ans` | `return ans;` | `return ans;` |

本题用到的接口：

- Python 内置 len(nums) 返回元素数量；range(1, n) 提供 1 到 n−1；max(a, b) 返回较大者。
- C++ vector::size() 无参数，返回无符号的长度类型；本题长度在 int 范围内，因此用 `static_cast<int>` 明确转换后与 int 下标比较。
- C++ std::max(a, b) 是 algorithm 中的标准库函数模板；本题两个参数均为 int，把返回值赋给整数变量即可。
- Java 数组的 length 是属性，不写括号；Math.max(int, int) 返回较大的 int，不会自动更新 ans，仍须赋值。

max 选择哪个候选值，是算法设计；它不会自己查找所有子数组。本题能覆盖所有起点，依赖前面的状态定义与推导。

## 复杂度与边界

- 时间 O(n)：每个元素处理一次，每轮只进行整数加法、比较与赋值。
- 辅助空间 O(1)：只保存 current、ans 和循环位置等固定数量的变量，不创建 dp 数组。
- 输出空间 O(1)：只返回整数和。
- 输入不修改、不排序、不复制；C++ 的引用参数表示可以访问原数组，本题仍只读取。

输入保证非空，长度不超过 100000，元素范围为 −10000～10000。任意区间和的绝对值至多 1000000000，本题 C++/Java 的 32 位 int 足够。若推广到更大的输入范围，应重新检查溢出风险；Python int 没有固定 32 位上限。

| 输入 | 答案 | 检查点 |
| --- | ---: | --- |
| [-2, 1, -3, 4, -1, 2, 1, -5, 4] | 6 | 题目示例，答案包含负数 |
| [1] | 1 | 单元素 |
| [-3, -2] | -2 | 全负数 |
| [0, 0, 0] | 0 | 零与并列最大值 |
| [-2, -3, 4, -1, 2] | 5 | 从第三个位置重新开始 |
| [4, -1, 2, 1] | 6 | 连续累加超过两个元素 |
| [5, -10, 1] | 5 | 最大值不在最后，必须保存 ans |
| [5, 4, -1, 7, 8] | 23 | 整个数组最优 |
| 100000 个 10000 | 1000000000 | 最大长度与数值范围 |

验证使用小数组的连续非空区间枚举作独立参考，大数组使用可直接推导的预期值，三种语言都检查输入不被修改。运行入口见[测试说明](../../../tests/README.md)。本地验证不代表替用户向力扣提交判题。
