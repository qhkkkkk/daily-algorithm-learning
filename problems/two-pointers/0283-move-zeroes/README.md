## 题意与例子

把所有 0 移到数组末尾，保持非零元素的原有顺序。需要直接修改原数组，不复制一个新数组作为结果。

```text
输入：[0, 1, 0, 3, 12]
结果：[1, 3, 12, 0, 0]
```

方法没有返回值，调用方检查的是传入数组被修改后的内容。

## 从错误尝试到快慢指针

最初的尝试是：遇到非零就往后走，遇到零就交换 `nums[i]` 与 `nums[i + 1]`。

这个办法有两个问题：

1. 当 `i` 已经是最后一个下标，访问 `i + 1` 会越界。
2. 只扫描一遍、每次只交换一次，无法处理连续零。例如 `[0, 0, 1]` 会得到 `[0, 1, 0]`，前面仍有零。

不必追着零向后搬。我们可以按顺序把非零元素放到前面：

- `i` 是快指针：扫描当前元素，每轮都前进。
- `pos` 是慢指针：记录下一个非零元素应该放的位置，遇到非零才前进。

这里的“指针”是算法中记录位置的变量，不要求使用 C/C++ 的指针类型。`i` 每次也只加 1；“快”表示移动次数不少于 `pos`，并不表示一次必须跳两格。

遇到非零元素时，把 `nums[i]` 与 `nums[pos]` 交换，再让 `pos` 加一。

## 逐步推演

初始 `pos = 0`。表中的下标和值是交换前读取的，最后一列是本轮结束后的 `pos`。

| i | 当前值 | 操作 | 数组 | pos |
| ---: | ---: | --- | --- | ---: |
| 0 | 0 | 跳过 | [0, 1, 0, 3, 12] | 0 |
| 1 | 1 | 交换下标 0 与 1 | [1, 0, 0, 3, 12] | 1 |
| 2 | 0 | 跳过 | [1, 0, 0, 3, 12] | 1 |
| 3 | 3 | 交换下标 1 与 3 | [1, 3, 0, 0, 12] | 2 |
| 4 | 12 | 交换下标 2 与 4 | [1, 3, 12, 0, 0] | 3 |

口诀：**i 找非零，pos 接收它。**

## 为什么正确

每轮开始时，可以把数组理解成三个区间：

```text
[0, pos)   已经按原顺序放好的非零元素
[pos, i)   已经扫描过、剩下的零
[i, n)     尚未处理的部分
```

遇到零，只移动扫描位置，零区间变长。遇到非零，把它放在前面已整理区间的末尾；当 `pos < i` 时，原来 `pos` 上的零被换到 `i`。

当 `pos == i` 时，当前元素与自己交换，值保持不变，也正确。因为我们按扫描顺序依次接收非零元素，所以它们的相对顺序不变。扫描结束后，前面都是非零，后面都是零。

## 三种语言源码

### C++

[源码](cpp/solution.cpp)。`vector<int>&` 让函数通过引用修改调用方的数组；`std::swap` 来自 `<utility>`。

```cpp
#include <utility>
#include <vector>

class Solution {
public:
    void moveZeroes(std::vector<int>& nums) {
        int pos = 0;  // 慢指针：下一个非零元素的放置位置
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            if (nums[i] != 0) {
                std::swap(nums[pos], nums[i]);
                ++pos;
            }
        }
    }
};
```

### Java

[源码](java/Solution.java)。`nums.length` 是数组长度，交换使用临时变量。

```java
class Solution {
    public void moveZeroes(int[] nums) {
        int pos = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                // 用临时变量保存旧值，交换两个位置的元素
                int temp = nums[pos];
                nums[pos] = nums[i];
                nums[i] = temp;
                pos++;
            }
        }
    }
}
```

### Python 3

[源码](python/solution.py)。循环自动给 `i` 下一个下标，不写 `i++`。

```python
class Solution:
    def moveZeroes(self, nums):
        pos = 0  # 下一个非零元素应该放的位置
        for i in range(len(nums)):
            if nums[i] != 0:
                nums[pos], nums[i] = nums[i], nums[pos]
                pos += 1
        # 原地修改，不需要 return nums
```

## 本次困惑与解答

这些问题来自本次练习。

### nums[pos] 是什么写法

方括号用于下标访问，下标从 0 开始。`pos` 是普通变量，可以作为下标：

```python
nums = [10, 20, 30]
pos = 1
print(nums[pos])  # 20，相当于 nums[1]
nums[pos] = 99    # 修改该位置，得到 [10, 99, 30]
```

`pos` 不是 Python 关键字，可以改名为 `write` 等。选一个能表达含义的名字有助于理解算法。

### nums[i] = nums[i] 有什么用

如果单独写这一句，就是把原值赋回自己，数组不变。但原答案是一整条交换语句，不能只截取其中一部分来理解：

```python
nums[pos], nums[i] = nums[i], nums[pos]
```

先计算右侧两个旧值，再按位置赋给左侧目标。例如左边两个位置原来是 `0`、`3`，右侧得到的是 `3`、`0`，赋回去就完成交换。

### 逗号分隔的同时赋值怎么理解

先用普通变量看：

```python
a = 0
b = 3
a, b = b, a
# a 变成 3，b 变成 0
```

对于本题这种交换，也可以写成三行，效果相同：

```python
temp = nums[pos]      # 先保存旧值
nums[pos] = nums[i]
nums[i] = temp
```

不能省掉 `temp`，直接写下面两句：

```python
# 错误交换示范：第一句覆盖旧值，第二句已经取不到原来的 nums[pos]
nums[pos] = nums[i]
nums[i] = nums[pos]
```

### 为什么我的 Python 报 SyntaxError

当时 `if nums[i] != 0` 和 `else` 都漏了冒号；还写了 Python 不支持的 `i++`。正确语法是：

```python
for i in range(len(nums)):
    if nums[i] != 0:
        pass  # 暂时不写内容时用 pass 占位
    else:
        pass
```

`for`、`if`、`else` 末尾要有冒号，下一层代码要缩进。实际快慢指针解法无需 `else`。

## 语言差别与常用语法

| 操作 | C++ | Java | Python |
| --- | --- | --- | --- |
| 初始化位置 | `int pos = 0;` | `int pos = 0;` | `pos = 0` |
| 数组长度 | `nums.size()` | `nums.length` | `len(nums)` |
| 访问元素 | `nums[i]` | `nums[i]` | `nums[i]` |
| 非零判断 | `if (nums[i] != 0) { … }` | 同 C++ | `if nums[i] != 0:` |
| 加一 | `++pos;` 或 `pos++;` | `pos++;` | `pos += 1` |
| 交换 | `std::swap(a, b)` | `temp` 三行交换 | `a, b = b, a` |
| 方法返回类型 | `void` | `void` | 没有显式 return 时返回 `None` |

C++/Java 的普通 `for` 把起点、条件、步进写在括号里；Python 的 `range(len(nums))` 依次提供 `0` 到 `len(nums)-1`。`range` 的右端点不包含在内。

原地修改方面，C++ 使用引用；Java 传入数组引用的值；Python 参数绑定到同一个列表对象。三者都能通过 `nums[i] = …` 修改原数组/列表。Java 或 Python 在函数内仅把参数名改指向一个新数组/列表，不会让调用方的变量自动指向新对象。

## 复杂度与边界

时间 O(n)，额外空间 O(1)。每个元素扫描一次，最多进行 n 次交换，不创建随输入增长的新数组。

| 输入 | 结果 | 检查点 |
| --- | --- | --- |
| [0] | [0] | 单个零 |
| [1] | [1] | 单个非零，自身交换 |
| [0, 0, 1] | [1, 0, 0] | 连续零 |
| [1, 2, 3] | [1, 2, 3] | 无零 |
| [0, 0, 0] | [0, 0, 0] | 全零 |
| [0, -1, 0, 2] | [-1, 2, 0, 0] | 负数也是非零 |

补充优化：当 `pos == i` 时可以跳过交换，减少无零前缀上的写入；这不改变时间复杂度。学习版保留统一交换，逻辑更直接。
